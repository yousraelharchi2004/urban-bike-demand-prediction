Engineered Features Breakdown

Feature Categories Explained

Time-Based Features

  • hour_squared (hour²) - Captures non-linear time effects
  • hour_sin / hour_cos - Cyclical time patterns (sine/cosine)
  • is_peak_hour - 7-9 AM & 5-7 PM peak periods
  • is_weekend - Weekend vs weekday patterns
  • rush_hour_intensity - Graduated peak hour scoring
  • day_of_week - Day of week encoding
High Impact (35%)

Weather Interaction Features

  • temp_hour_interaction - Temperature × Time interaction
  • temp_squared - Non-linear temperature effects
  • temp_category_* - Categorical weather classification
  • comfort_index - Temperature-Humidity balance
  • good_biking_conditions - Combined weather factors flag
  • wind_speed_squared - Non-linear wind effect
Medium Impact (25%)

Interaction Features

  • temp_hour_interaction - How temperature effect varies by time
  • comfort_index - Combined weather comfort metric
  • hour_sin/hour_cos - Cyclical time interactions
High Impact (30%)

Technical Implementation

Feature Engineering Code Samples:

# Time-based features
df['hour_squared'] = df['hour'] ** 2
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)
df['is_weekend'] = (df['day_of_week'] >= 5).astype(int)

# Peak hour indicators
df['is_morning_peak'] = ((df['hour'] >= 7) & (df['hour'] <= 9)).astype(int)
df['is_evening_peak'] = ((df['hour'] >= 17) & (df['hour'] <= 19)).astype(int)
df['is_peak_hour'] = (df['is_morning_peak'] | df['is_evening_peak']).astype(int)

# Weather interaction features
df['temp_hour_interaction'] = df['temperature'] * df['hour']
df['temp_squared'] = df['temperature'] ** 2
df['comfort_index'] = df['temperature'] - (df['humidity'] / 10)

# Rush hour intensity
def rush_hour_intensity(hour):
    if hour in [7, 8, 17, 18]: return 1.0
    elif hour in [6, 9, 16, 19]: return 0.6
    elif hour in [10, 15, 20]: return 0.3
    else: return 0.0

df['rush_hour_intensity'] = df['hour'].apply(rush_hour_intensity)

# Good biking conditions
df['good_biking_conditions'] = ((df['temperature'] >= 10) & 
                                (df['temperature'] <= 30) & 
                                (df['rainfall'] == 0) & 
                                (df['snowfall'] == 0) & 
                                (df['wind_speed'] < 10)).astype(int)

# Categorical encoding
df = pd.get_dummies(df, columns=['season', 'temp_category', 'time_of_day'])
