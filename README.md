# 🚲 Urban Bike Rental Demand Prediction System

## 🎓 Graduation Project - Multimodal Feature Analysis

### 📋 Overview
A machine learning system that predicts bike rental demand in urban areas using multimodal features including weather, time, and seasonal patterns.

### ✨ Features
- **Real-time predictions** with Random Forest model
- **Model performance analytics** with detailed metrics
- **Feature importance analysis**
- **RESTful API** for programmatic access
- **Interactive web interface**
